# REDI — Readiness Engine for Data Integration

REDI transforms raw scientific data into AI-ready datasets. It supports multiple scientific
domains and operates in four primary modes:

* **demo** — Download a sample dataset and run the pipeline end-to-end (start here)
* **run** — Execute the full REDI pipeline to transform data
* **inspect** — Observe existing workflows (Snakemake, Nextflow, bash) and generate Data Cards
* **discover** — Analyze unknown datasets and propose processing pipelines
* **validate** — Compare REDI output against ground-truth data
