redi.downloaders
================

Data acquisition modules for downloading scientific datasets from remote sources
before pipeline processing.

redi.downloaders.esgf
---------------------

Downloads CMIP6 climate model data from the Earth System Grid Federation (ESGF).

redi.downloaders.cds
--------------------

Downloads ERA5 reanalysis data from the Copernicus Climate Data Store (CDS).

.. note::
   CDS access requires an API key configured in ``~/.cdsapirc``.
