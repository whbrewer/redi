================================================================================
STEP 1: DATA CLEANING
================================================================================

**Goal:** Handle missing values, remove unusable columns, fix data types

**Actions:**

1.1 Remove columns with 100% missing values:
    - MACHINE_PARTITION
    - PYTHON_EXECUTABLE_PATH
    - PYTHON_EXECUTABLE_VERSION

1.2 Handle MODE column (48% missing):
    - Fill with 'UNKNOWN' or create 'MODE_MISSING' indicator feature
    - Option: Drop if not predictive after testing

1.3 Handle TASK_EXIT_CODES (16% missing):
    - Option A: Fill with empty string '' for missing
    - Option B: Create IS_TASK_EXIT_CODES_AVAILABLE boolean feature

1.4 Fix mixed data types:
    - Specify dtypes when loading CSV (columns 34, 37, 38, 39, 62)
    - Convert to appropriate types (int64, float64, object)

1.5 Handle outliers in target variable:
    - 13.89% of jobs have queue times > 463 seconds
    - Options:
      a) Winsorize: Cap at 99th percentile
      b) Log transform: log(1 + QUEUED_WAIT_SECONDS)
      c) Keep but use robust loss (Huber, MAE vs MSE)

**Code Example:**

```python
import pandas as pd
import numpy as np

# Load with explicit dtypes
dtype_dict = {
    'EXIT_CODE': 'str',
    'MODE': 'str',
    'RESID': 'str',
    # ... specify all mixed columns
}

df = pd.read_csv('ANL-ALCF-DJC-AURORA_20250127_20251031.csv',
                 dtype=dtype_dict,
                 low_memory=False)

# Remove 100% missing columns
df = df.drop(columns=['MACHINE_PARTITION', 
                      'PYTHON_EXECUTABLE_PATH',
                      'PYTHON_EXECUTABLE_VERSION'])

# Handle MODE missing values
df['MODE'] = df['MODE'].fillna('UNKNOWN')

# Handle TASK_EXIT_CODES
df['TASK_EXIT_CODES'] = df['TASK_EXIT_CODES'].fillna('')

# Optional: Log transform target
df['QUEUED_WAIT_SECONDS_LOG'] = np.log1p(df['QUEUED_WAIT_SECONDS'])
```

================================================================================
STEP 2: TEMPORAL FEATURE ENGINEERING
================================================================================

**Goal:** Extract time-based features from timestamps

**Actions:**

2.1 Parse timestamp columns:
    - QUEUED_TIMESTAMP
    - START_TIMESTAMP
    - END_TIMESTAMP

2.2 Extract temporal features:
    - Hour of day (0-23)
    - Day of week (0-6)
    - Is weekend (boolean)
    - Is business hours (8am-5pm weekdays)
    - Month of year
    - Week of year

2.3 Create derived time features:
    - Queue depth proxy: Jobs submitted in same hour
    - Time since last submission (requires sorting)
    - Rolling average queue time (requires temporal ordering)

**Why these matter:**
Queue times vary by time of day and day of week due to:
- Peak usage during business hours
- Batch job submissions
- Scheduled maintenance windows

**Code Example:**

```python
# Parse timestamps
df['QUEUED_TIMESTAMP'] = pd.to_datetime(df['QUEUED_TIMESTAMP'])

# Extract features
df['queued_hour'] = df['QUEUED_TIMESTAMP'].dt.hour
df['queued_day_of_week'] = df['QUEUED_TIMESTAMP'].dt.dayofweek
df['queued_is_weekend'] = (df['queued_day_of_week'] >= 5).astype(int)
df['queued_is_business_hours'] = (
    (df['queued_hour'] >= 8) & 
    (df['queued_hour'] < 17) & 
    (df['queued_day_of_week'] < 5)
).astype(int)
df['queued_month'] = df['QUEUED_TIMESTAMP'].dt.month
df['queued_week_of_year'] = df['QUEUED_TIMESTAMP'].dt.isocalendar().week

# Proxy for queue depth (jobs per hour)
df['jobs_in_same_hour'] = df.groupby(
    df['QUEUED_TIMESTAMP'].dt.floor('H')
)['COBALT_JOBID'].transform('count')
```

================================================================================
STEP 3: RESOURCE UTILIZATION FEATURES
================================================================================

**Goal:** Create HPC-specific resource efficiency features

**Actions:**

3.1 Compute utilization ratios:
    - Node utilization = NODES_USED / NODES_REQUESTED
    - Core utilization = CORES_USED / CORES_REQUESTED
    - Walltime efficiency = RUNTIME_SECONDS / WALLTIME_SECONDS
    - Core-hour efficiency = USED_CORE_HOURS / REQUESTED_CORE_HOURS

3.2 Resource request features:
    - Job size category (small: <16 nodes, medium: 16-512, large: >512)
    - Is full-system job (NODES_REQUESTED > 5000)
    - Resource intensity = REQUESTED_CORE_HOURS / WALLTIME_SECONDS

3.3 Historical user/project features:
    - Average queue time for this user (requires grouping)
    - Average queue time for this project
    - User's typical job size
    - Project's resource consumption pattern

**Why these matter:**
- Larger jobs typically wait longer (scheduler backfill)
- Users/projects with history of efficient usage may get priority
- Job size affects scheduling decisions

**Code Example:**

```python
# Utilization ratios
df['node_utilization'] = df['NODES_USED'] / df['NODES_REQUESTED'].replace(0, 1)
df['core_utilization'] = df['CORES_USED'] / df['CORES_REQUESTED'].replace(0, 1)
df['walltime_efficiency'] = df['RUNTIME_SECONDS'] / df['WALLTIME_SECONDS'].replace(0, 1)

# Job size categories
df['job_size_category'] = pd.cut(df['NODES_REQUESTED'],
                                   bins=[0, 16, 512, float('inf')],
                                   labels=['small', 'medium', 'large'])

# Historical features (careful with temporal leakage!)
# Must compute using only past data, not future
df_sorted = df.sort_values('QUEUED_TIMESTAMP')
df_sorted['user_avg_queue_time'] = df_sorted.groupby('USERNAME_GENID')['QUEUED_WAIT_SECONDS'].expanding().mean().reset_index(level=0, drop=True)
```

================================================================================
STEP 4: CATEGORICAL ENCODING
================================================================================

**Goal:** Convert categorical variables to numerical format

**Actions:**

4.1 High-cardinality features (QUEUE_NAME: 153 values):
    - Option A: Target encoding (mean queue time per queue)
    - Option B: Frequency encoding (job count per queue)
    - Option C: Embedding layer (if using deep learning)

4.2 Low-cardinality features:
    - ALLOCATION_AWARD_CATEGORY (4 values): One-hot encoding
    - SIZE_BUCKETS3 (4 values): One-hot encoding
    - EXIT_STATUS (126 values): Target encoding or group rare categories

4.3 Binary features:
    - Already encoded (IS_PYTHON, IS_SINGLE, etc.)
    - Ensure 0/1 encoding (not True/False)

4.4 Text features:
    - JOB_NAME: Extract patterns (hash, length, contains keywords)
    - LOCATION: Parse structure, one-hot encode

**Code Example:**

```python
from sklearn.preprocessing import LabelEncoder, OneHotEncoder

# Target encoding for QUEUE_NAME
queue_means = df.groupby('QUEUE_NAME')['QUEUED_WAIT_SECONDS'].mean()
df['queue_name_encoded'] = df['QUEUE_NAME'].map(queue_means)

# One-hot encode low-cardinality
df = pd.get_dummies(df, 
                    columns=['ALLOCATION_AWARD_CATEGORY', 'SIZE_BUCKETS3'],
                    drop_first=True)  # Avoid dummy variable trap

# Frequency encode high-cardinality
username_counts = df['USERNAME_GENID'].value_counts()
df['username_frequency'] = df['USERNAME_GENID'].map(username_counts)
```

================================================================================
STEP 5: FEATURE NORMALIZATION
================================================================================

**Goal:** Scale numerical features for ML models

**Actions:**

5.1 Identify feature types:
    - Continuous: NODES_REQUESTED, CORES_REQUESTED, WALLTIME_SECONDS
    - Count: jobs_in_same_hour, username_frequency
    - Ratio: utilization features (already 0-1)
    - Binary: IS_* features (no scaling needed)

5.2 Choose scaling method:
    - StandardScaler (z-score): Good for normally distributed features
    - RobustScaler: Better for features with outliers
    - MinMaxScaler: For features that need [0,1] range

5.3 Important: Fit scaler on training data only!
    - Fit on train set
    - Transform train, val, test sets
    - Save scaler parameters for inference

**Code Example:**

```python
from sklearn.preprocessing import RobustScaler
import joblib

# Define features to scale
scale_features = ['NODES_REQUESTED', 'CORES_REQUESTED', 'WALLTIME_SECONDS',
                  'REQUESTED_CORE_HOURS', 'jobs_in_same_hour',
                  'user_avg_queue_time', 'queue_name_encoded']

# Fit scaler on training data only
scaler = RobustScaler()
X_train[scale_features] = scaler.fit_transform(X_train[scale_features])

# Transform validation and test sets
X_val[scale_features] = scaler.transform(X_val[scale_features])
X_test[scale_features] = scaler.transform(X_test[scale_features])

# Save scaler for inference
joblib.dump(scaler, 'queue_time_scaler.pkl')
```

================================================================================
STEP 6: TRAIN/VALIDATION/TEST SPLIT
================================================================================

**Goal:** Create proper temporal splits to avoid data leakage

**Actions:**

6.1 CRITICAL: Use temporal split, NOT random split
    - Train: Earliest 70% of data (by QUEUED_TIMESTAMP)
    - Validation: Next 15%
    - Test: Most recent 15%
    - Rationale: Predict future queue times based on past patterns

6.2 Sort data by timestamp before splitting:
    ```python
    df = df.sort_values('QUEUED_TIMESTAMP')
    
    n = len(df)
    train_end = int(0.70 * n)
    val_end = int(0.85 * n)
    
    df_train = df.iloc[:train_end]
    df_val = df.iloc[train_end:val_end]
    df_test = df.iloc[val_end:]
    ```

6.3 Verify no temporal leakage:
    - Check that max(train_timestamps) < min(val_timestamps)
    - Check that max(val_timestamps) < min(test_timestamps)

6.4 Alternative: Time-series cross-validation
    - For more robust evaluation
    - Use sklearn.model_selection.TimeSeriesSplit

STEP 7: FORMAT CONVERSION & SHARDING
================================================================================

**Goal:** Convert to AI-optimized format and shard for distributed training

**Actions:**

7.1 Choose output format:
    - **Parquet (Recommended)**: Fast columnar format, good compression
    - **HDF5**: Good for arrays, slower for tabular
    - **NPZ**: Simple, good for NumPy arrays
    - **WebDataset**: Best for PyTorch distributed training

7.2 Shard data for efficient loading:
    - Target shard size: 100 MB - 1 GB
    - Create separate shards for train/val/test
    - For 663K records: ~10-20 shards

7.3 Save metadata:
    - Feature names and types
    - Scaler parameters
    - Train/val/test split indices
    - Column statistics (min, max, mean, std)

**Code Example (Parquet):**

```python
import pyarrow.parquet as pq

# Determine shard size
shard_size = 50000  # records per shard

# Save training shards
for i in range(0, len(df_train), shard_size):
    shard = df_train.iloc[i:i+shard_size]
    shard_num = i // shard_size
    shard.to_parquet(f'data/train/shard_{shard_num:04d}.parquet',
                     compression='snappy',
                     index=False)

# Same for val and test
for i in range(0, len(df_val), shard_size):
    shard = df_val.iloc[i:i+shard_size]
    shard_num = i // shard_size
    shard.to_parquet(f'data/val/shard_{shard_num:04d}.parquet',
                     compression='snappy',
                     index=False)

for i in range(0, len(df_test), shard_size):
    shard = df_test.iloc[i:i+shard_size]
    shard_num = i // shard_size
    shard.to_parquet(f'data/test/shard_{shard_num:04d}.parquet',
                     compression='snappy',
                     index=False)
```

================================================================================
MODEL RECOMMENDATIONS
================================================================================

For queue time prediction, consider these models:

1. **Gradient Boosting (XGBoost/LightGBM/CatBoost)**
   - Best for tabular data
   - Handles non-linear relationships well
   - Fast training and inference
   - Can handle missing values
   - **Recommended starting point**

2. **Random Forest**
   - Good baseline
   - Robust to outliers
   - Provides feature importances

3. **Neural Network (MLP)**
   - Can capture complex patterns
   - Requires more data and tuning
   - Consider for very large datasets

4. **Linear Models (Ridge/Lasso)**
   - Fast and interpretable
   - Good baseline for comparison
   - May underfit complex patterns

**Evaluation Metrics:**
- MAE (Mean Absolute Error): Easy to interpret
- RMSE (Root Mean Squared Error): Penalizes large errors
- MAPE (Mean Absolute Percentage Error): Relative error
- R² score: Explained variance

```python
# pipeline.py - Complete HPC Queue Time Prediction Pipeline

import pandas as pd
import numpy as np
from sklearn.preprocessing import RobustScaler
from sklearn.model_selection import TimeSeriesSplit
import joblib

# STEP 1: Load and Clean
print("Step 1: Loading and cleaning data...")
df = pd.read_csv('../hpc/ANL-ALCF-DJC-AURORA_20250127_20251031.csv',
                 low_memory=False)

# Remove 100% missing columns
df = df.drop(columns=['MACHINE_PARTITION', 
                      'PYTHON_EXECUTABLE_PATH',
                      'PYTHON_EXECUTABLE_VERSION'])

# Handle missing values
df['MODE'] = df['MODE'].fillna('UNKNOWN')
df['TASK_EXIT_CODES'] = df['TASK_EXIT_CODES'].fillna('')

# STEP 2: Temporal Features
print("Step 2: Engineering temporal features...")
df['QUEUED_TIMESTAMP'] = pd.to_datetime(df['QUEUED_TIMESTAMP'])
df['queued_hour'] = df['QUEUED_TIMESTAMP'].dt.hour
df['queued_day_of_week'] = df['QUEUED_TIMESTAMP'].dt.dayofweek
df['queued_is_weekend'] = (df['queued_day_of_week'] >= 5).astype(int)
df['queued_is_business_hours'] = (
    (df['queued_hour'] >= 8) & 
    (df['queued_hour'] < 17) & 
    (df['queued_day_of_week'] < 5)
).astype(int)
df['jobs_in_same_hour'] = df.groupby(
    df['QUEUED_TIMESTAMP'].dt.floor('H')
)['COBALT_JOBID'].transform('count')

# STEP 3: Resource Features
print("Step 3: Engineering resource features...")
df['node_utilization'] = df['NODES_USED'] / df['NODES_REQUESTED'].replace(0, 1)
df['walltime_efficiency'] = df['RUNTIME_SECONDS'] / df['WALLTIME_SECONDS'].replace(0, 1)

# STEP 4: Categorical Encoding
print("Step 4: Encoding categorical variables...")
queue_means = df.groupby('QUEUE_NAME')['QUEUED_WAIT_SECONDS'].mean()
df['queue_name_encoded'] = df['QUEUE_NAME'].map(queue_means)

df = pd.get_dummies(df, 
                    columns=['ALLOCATION_AWARD_CATEGORY', 'SIZE_BUCKETS3'],
                    drop_first=True)

# STEP 5: Target Transform
print("Step 5: Transforming target variable...")
df['target'] = np.log1p(df['QUEUED_WAIT_SECONDS'])

# STEP 6: Train/Val/Test Split (Temporal)
print("Step 6: Creating temporal splits...")
df = df.sort_values('QUEUED_TIMESTAMP')

n = len(df)
train_end = int(0.70 * n)
val_end = int(0.85 * n)

df_train = df.iloc[:train_end].copy()
df_val = df.iloc[train_end:val_end].copy()
df_test = df.iloc[val_end:].copy()

print(f"Train: {len(df_train):,} | Val: {len(df_val):,} | Test: {len(df_test):,}")

# STEP 7: Feature Selection
feature_cols = [
    'NODES_REQUESTED', 'CORES_REQUESTED', 'GPUS_REQUESTED',
    'WALLTIME_SECONDS', 'REQUESTED_CORE_HOURS',
    'queued_hour', 'queued_day_of_week', 'queued_is_weekend',
    'queued_is_business_hours', 'jobs_in_same_hour',
    'queue_name_encoded', 'node_utilization', 'walltime_efficiency',
    'IS_SINGLE', 'IS_CONSECUTIVE', 'IS_MULTILOCATION', 
    'IS_SUBBLOCK', 'IS_PYTHON'
]

# Add one-hot encoded columns
feature_cols += [col for col in df_train.columns if 
                 col.startswith('ALLOCATION_AWARD_CATEGORY_') or 
                 col.startswith('SIZE_BUCKETS3_')]

# STEP 8: Normalization
print("Step 7: Normalizing features...")
scale_features = ['NODES_REQUESTED', 'CORES_REQUESTED', 'GPUS_REQUESTED',
                  'WALLTIME_SECONDS', 'REQUESTED_CORE_HOURS',
                  'jobs_in_same_hour', 'queue_name_encoded']

scaler = RobustScaler()
df_train[scale_features] = scaler.fit_transform(df_train[scale_features])
df_val[scale_features] = scaler.transform(df_val[scale_features])
df_test[scale_features] = scaler.transform(df_test[scale_features])

# STEP 9: Save to Parquet
print("Step 8: Saving to Parquet format...")
import os
os.makedirs('data/train', exist_ok=True)
os.makedirs('data/val', exist_ok=True)
os.makedirs('data/test', exist_ok=True)

shard_size = 50000

for i in range(0, len(df_train), shard_size):
    shard = df_train.iloc[i:i+shard_size][feature_cols + ['target']]
    shard.to_parquet(f'data/train/shard_{i//shard_size:04d}.parquet',
                     compression='snappy', index=False)

for i in range(0, len(df_val), shard_size):
    shard = df_val.iloc[i:i+shard_size][feature_cols + ['target']]
    shard.to_parquet(f'data/val/shard_{i//shard_size:04d}.parquet',
                     compression='snappy', index=False)

for i in range(0, len(df_test), shard_size):
    shard = df_test.iloc[i:i+shard_size][feature_cols + ['target']]
    shard.to_parquet(f'data/test/shard_{i//shard_size:04d}.parquet',
                     compression='snappy', index=False)

# Save scaler and metadata
joblib.dump(scaler, 'data/scaler.pkl')
joblib.dump({'features': feature_cols, 
             'scale_features': scale_features},
            'data/metadata.pkl')

print("✓ Pipeline complete! Data ready for training.")
print(f"  - Training shards: {len(range(0, len(df_train), shard_size))}")
print(f"  - Validation shards: {len(range(0, len(df_val), shard_size))}")
print(f"  - Test shards: {len(range(0, len(df_test), shard_size))}")
```
